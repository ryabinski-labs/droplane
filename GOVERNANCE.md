# Governance

Droplane is a small project led by its maintainers listed in [MAINTAINERS.md](MAINTAINERS.md).

- **Decisions:** made in issues and pull requests. Maintainers decide when there is disagreement.
- **Merging:** maintainers merge once required CI checks pass.
- **Releases:** a maintainer tags a release. Signing and notarization credentials stay with maintainers and are never in the repository or exposed to pull requests from forks.
- **Security reports:** handled privately as described in [SECURITY.md](SECURITY.md).
- **Code of conduct:** enforced by the maintainers under [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Name:** "Droplane" names this project. Forks may reuse the code under the MIT License but should use a different name and icon for builds they distribute.
- **Roadmap:** there is no committed roadmap. Planned work appears in issues.
