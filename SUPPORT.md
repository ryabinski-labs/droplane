# Support

Droplane is maintained by volunteers. There is no response-time guarantee.

- **Bugs and feature requests:** open an issue at https://github.com/ryabinski-labs/droplane/issues using the templates.
- **Security problems:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

## The phone doesn't show up

1. Use a data cable. Some cables only charge.
2. Unlock the phone, then pull down the notification shade and tap the USB notification.
3. Choose **File transfer** (on Pixel phones, "File transfer / Android Auto").
4. Quit any other phone manager, such as Android File Transfer or Samsung Smart Switch. Only one app can use the phone at once.
5. Unplug the phone, plug it back in, and press Refresh (⌘R).

When you file a bug, include the phone make and model, the Android version, and what the window shows. Please do not attach files from your phone.

Droplane works with phones that support MTP. Some phone makers handle MTP differently, so a phone-specific bug report is useful.
