# Security Policy

## Supported Versions

Droplane has no public release yet. Once releases exist, only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately. Do not open a public issue.

Use GitHub's private vulnerability reporting: https://github.com/ryabinski-labs/droplane/security/advisories/new

Helpful details: the Droplane version, your macOS version, the phone model, and steps to reproduce. Do not include personal files.

## Disclosure

This is a volunteer project, so these are goals and not guarantees. We aim to acknowledge a report within 7 days, to share a fix plan or ask questions within 30 days, and to publish a fix and an advisory once a fixed release is available. We will credit reporters who want credit.

## Scope

In scope: the Droplane app and its build and release scripts. Out of scope: vulnerabilities in libmtp, libusb, macOS, or a phone's own MTP software. Report those to their projects, and let us know so we can ship the fixed library.
