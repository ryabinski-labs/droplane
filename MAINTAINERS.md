# Maintainers

This file is the human-readable source of truth for project maintainers. It is mirrored to GitHub repository permissions through the `ryabinski-labs` organization.

Maintainers can merge pull requests to the default branch after required CI checks pass. A blanket approving review is not required, and non-maintainers cannot merge even if checks pass.

| Maintainer | GitHub | Contact | Areas |
| --- | --- | --- | --- |
| Yoni Ryabinski | @cigan1 | cigan1@gmail.com | everything, release signing |

To become a maintainer, open an issue or contact an existing maintainer. Adding or removing a maintainer is a change to this file and to repository permissions.
